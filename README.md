# 2P Games

Two-player browser games over Socket.IO rooms. First game: Skribble.

> Work in progress. The full README (rules, environment, two-browser testing, and the
> single-process in-memory room storage limitation) lands at integration time.
> See `docs/WORKSTREAMS.md` for the parallel-agent layout.

```sh
npm install
cp apps/server/.env.example apps/server/.env
cp apps/web/.env.example apps/web/.env
npm run dev
```
